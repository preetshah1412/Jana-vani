# Project reports

- `Jana_Vani_Project_Report_42_Pages.docx` is the project report for the Jana Vani community-poll prototype.
- `Jana_Vani_IEEE_Research_Paper_7_Page.docx` is the seven-page research-paper draft about the prototype. It is a student research-paper draft and is not an IEEE publication or acceptance claim.

Both documents describe Jana Vani as an independent, non-binding community-poll demonstration. They do not present it as an official Indian election service.
